# All Vall Minigames

Hub de minijuegos interactivos y contenido estimulativo (Jocs Interactius / Videos Estimulatius).

- **Entrada:** `index.html` — navegación por paneles de juegos y vídeos.
- **Juegos:** en `Games/`, organizados por autor. Cada juego tiene su carpeta con HTML, CSS, JS y recursos.
- **Contenido estimulativo:** en `Estimulacio/` — vídeos y material no interactivo.
- **Capturas:** en `Capturas/` — imágenes de vista previa del hub.

Los juegos incluyen un botón de vuelta (Enrere / Volver) al hub.
